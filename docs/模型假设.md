# 剪切应力量级模型：假设、来源与检查

日期：2026-10-17。模型标识：`depth-gradient-scale-v0.1`。

## 当前模型的含义

本版实现策划书的“特征流速/特征长度 × 动力黏度”思路，作为透明、可复算的尺度估算。采用轨道线速度作为流速尺度，平均液深作为速度梯度长度。**这两项是项目的简化假设，尚未通过实际流场校准。**

输出是所选尺度下的剪切应力（mPa），不是单位为N的剪切力；也不代表壁面或组织表面某位置的峰值或平均值。文献中的CFD结果不能仅靠数值相近就视为对本版模型的验证。

## 输入与单位

| 输入 | 页面单位 | 用途 |
| --- | --- | --- |
| 晃幅D，即轨道直径 | mm | 除以2得到轨道半径，不能当作半径直接使用 |
| 转速n | rpm | 除以60换成每秒转数 |
| 圆形平底容器内径d | mm | 计算底面积；使用实际单孔或单皿内径 |
| 单孔/单皿液量V | mL | 计算平均液深；不是整板总液量 |
| 动力黏度下限、上限 | mPa·s | 两端分别计算剪切尺度；只有一个值时两端填同值 |
| 黏度对应温度 | °C | 记录参数条件；本版没有自动温度—黏度换算 |

网页默认25 mm、80 rpm、35 mm内径、3 mL及0.7–1.0 mPa·s，仅为输入演示，不是经校准的培养条件或普适参数。用户应替换成自己的设备尺寸、液量和对应温度下的培养基黏度。

## 公式与量纲

先统一为SI单位：D和d乘10⁻³得到m，V乘10⁻⁶得到m³，μ乘10⁻³得到Pa·s。

- 轨道半径a=D/2。
- 角速度ω=2πn/60，单位s⁻¹。
- 轨道线速度尺度U=ωa，单位m/s。
- 平均液深h=V/[π(d/2)²]，单位m。
- 速度梯度尺度γ=U/h，单位s⁻¹。
- 剪切应力尺度τ=μγ，单位Pa；乘1000得到mPa。

代码保留页面黏度的mPa·s单位并直接乘γ，因此结果直接为mPa，不再重复乘1000。

范围仅为同一几何和转速下，输入黏度两端对应的情景范围。**它不包含模型误差，不是置信区间，也不是生物安全范围。**

## 假设与未覆盖项

1. 牛顿流体；黏度在每个输入情景下为常数。
2. 圆形平底、直壁容器；液深以静态平均值近似。其他几何明确拒绝计算。
3. 组织占据的体积忽略；轨道线速度不是测得的局部流体速度；液深不是已经验证的边界层厚度。
4. 未解析自由液面波动、共振、非线性流动、湍流和局部边界层。特别是在干底、溅液、强波动等情况下，不能据此描述真实剪切分布。
5. 未计算组织相对流体运动、组织间碰撞、悬浮或氧供给。
6. 零转速只令本模型的轨道驱动贡献为零，不能推断所有来源的流动和剪切均为零。
7. 本版不输出“超标倍数”或安全转速；后续双边界模块还需要独立核查边界模型及适用证据。

## 候选条件扫描（screening.py，2026-10-18）

1. 扫描是在用户已填写并算出的双边界区间输入之上，对“轨道直径 × 转速”离散网格逐点判定是否落入剪切上界、悬浮下界、氧供给下界、设备上限与传质Re范围；判定理由逐条保留。
2. 一次最多300组。轨道直径逐个替换后，其余输入（容器、液量、黏度、阈值、速度系数）保持不变，因此结论仍只对这些输入成立。
3. 目标等效直径与圆形度仅作为待实验验证的记录，不进入计算。当前条件—形态配对训练样本为0组，预测误差未评估；扫描不预测形态是否达标，也不对满足约束的候选作优劣排序。
4. 满足约束不等于实验安全；全部模型假设沿用上文。

## 核对过的文献与使用方式

- Driessen等，2020，*Micromachines*，DOI [10.3390/mi11060552](https://doi.org/10.3390/mi11060552)，[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7345652/)：式4给出牛顿流体壁面剪切应力与局部速度梯度的关系。该研究通过CFD处理轨道摇床的几何与液面；它不验证本项目以U/h替代局部梯度的选择。文中0.7 mPa·s、37 °C为该文的建模物性，不能作为所有培养基的通用值。
- 策划书所列2019年类器官培养流体模拟论文，DOI [10.1186/s12861-019-0183-y](https://doi.org/10.1186/s12861-019-0183-y)，[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6404276/)：六孔板90 rpm条件报告约45 mPa局部最大值。该证据来自CFD；与本尺度估算的统计口径不同，仅展示为独立文献背景，不拟合为通用校正系数，不用作安全阈值。

为精化物理模型，后续需要匹配轨道尺寸、容器、液量、物性及空间/时间统计口径的验证数据。单凭rpm和一个峰值不能完成这种校准。

## 软件验证与可复算例

独立单位算例：轨道直径20 mm、60 rpm、容器内径20 mm、液量π mL、黏度1–2 mPa·s。

- 底面积=π×10⁻⁴ m²；液深=0.01 m。
- 线速度=0.02π m/s；梯度=2π s⁻¹。
- 输出=2π–4π mPa，约6.283–12.566 mPa。

默认演示：液深3.11813766 mm、轨道速度0.104719755 m/s、梯度33.58407053 s⁻¹，输出23.50884937–33.58407053 mPa。
