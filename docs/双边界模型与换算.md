# 双边界条件模型与转速换算

当前版本为条件模型，不是经实验验证的安全建议。没有必要参数或依据时不产生区间。所有输入及每个边界随报告保存。

## 上界：剪切尺度约束

沿用 `模型假设.md` 的τ=μU/h模型。固定几何时本模型τ正比于rpm；用黏度上限计算τ(n=1 rpm)，再以用户提供的剪切约束除以该值求n上界。该阈值没有硬编码的生物安全默认值。设备最高转速是另一个上界。

## 下界：悬浮

以球体终端沉降作筛选尺度。Stokes速度w₀=Δρgd²/(18μ)，但对于Re不够小的球体，不能直接使用它。程序迭代求解Schiller–Naumann阻力关系：w[1+0.15Re^0.687]=w₀，Re=ρwd/μ，限Re<1000。

假设可用于悬浮的有效流速为βs×U轨道，要求该速度不小于沉降速度。βs必须由适用实验或流场依据提供；轨道运动本身不直接等于向上的悬浮流速。本版仅提供此代理约束，不能将其当作经过验证的悬浮判据。

## 下界：外部传质与内部氧扩散

球体、稳态、均匀恒定体积耗氧Q，培养液体相氧浓度Cbulk恒定。忽略细胞分布异质性、耗氧随氧浓度变化、培养液与气相供氧动态及坏死后耗氧变化。

- 外部Sherwood情景关系：Sh=2+0.6Re^0.5Sc^(1/3)，kL=Sh×D液/d。
- Re=ρ×βt×U轨道×d/μ；Sc=μ/(ρD液)。βt是用户提供的表面相对速度比例。
- 表面氧浓度：Cs=Cbulk−Qd/(6kL)。
- 球心氧浓度：Cc=Cs−Qd²/(24D组织)。
- 要求Cc≥用户给定Ccrit，反解kL、Re与最低rpm。

若Cbulk−Ccrit−Qd²/(24D组织)≤0，连理想表面供氧也不能满足条件，不因提高转速而自动给出解。若外部传质所需Re>200，则提示超出本版关联式的计算范围。本版还用Re≤200限制最终区间上端。**Re条件不等于完成适用性验证：该关联式及高Schmidt数情景、组织表面形状、βt都未在本体系校准。**

结果取两个黏度端点下较严格的下界及上界，再与设备范围取交集；同时给出密度差与耗氧率各0.5、1、2倍的9种情景。原始恒定耗氧解在氧耗竭时不再描述实际组织状态，不把形式上的负氧浓度作为真实浓度报告。

## 换算

- 等轨道线速度：n₂=n₁D₁/D₂。
- 等轨道加速度：n₂=n₁√(D₁/D₂)。它不是通用“等剪切”公式。
- 等模型剪切：用文献几何和物性计算τ₁，再用目标模型τ₂(n=1)反解n₂=τ₁/τ₂(1)。该模式明确限于液深尺度模型，不保证真实局部剪切或生物学结局相同。
