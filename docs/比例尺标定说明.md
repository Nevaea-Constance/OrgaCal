# 比例尺标定

更新日期：2026-10-17。本步在已有多目标识别后加入手动比例尺换算。

## 怎么使用

1. 选择图片并点击“开始分析”，核对轮廓，排除气泡、碎屑、标尺或文字等误识别区域。
2. 找到对应原始图片的可靠标尺。输入标尺标注的真实长度（µm）和在原图中测量的两端像素距离（px）。
3. 点击“应用比例尺”。原像素表仍保留，下方出现微米结果表；两张表的编号和排除状态一致。
4. 修改长度后需重新应用；“清除比例尺”会清空两个输入值和微米结果；换图也会清除比例尺。重新分析后需重新应用，输入值只可用于核对同一图片。

举例说明：若标尺标注100 µm，在原图中量得200 px，则1 px=0.5 µm。100 px的长度换算为50 µm，10000 px²的面积换算为2500 µm²。**这些是假设数值，不是论文示例的真实标定。**

像素距离应从图像软件读取原始图片上的两端坐标或长度，不应测量浏览器缩略图、屏幕截图或显示器上的长度。横向标尺可用两端x坐标之差；斜向标尺采用两点的欧氏距离。

## 计算口径

- s=标尺真实长度/原图像素长度，单位µm/px。
- 面积=A_px²×s²；周长=P_px×s；等效直径=D_px×s；Circularity保持不变。
- 采用未经过显示舍入的像素测量值换算；微米表显示6位有效数字，不代表具有6位有效数字的实验精度。
- 网页缩小识别的坐标已在原算法中换回原图像素，因此标定只再应用一次，不重复乘预览缩放倍数。
- 当前方法使用统一的横纵比例，要求未发生不等比例拉伸。标尺长度不能超过原图对角线，像素长度至少1 px，两个长度必须为正的有限数值。
- 标定是用户输入的长度换算，不代表自动验证了标尺来源或识别精度。默认无标定；2x/4x倍率本身不足以确定比例尺。
- 现有4张论文示例未内置微米标定，数据索引中的未知比例尺保持为空。
- 未改变现有分割算法，未实现批量标定、自动识别标尺、轮廓人工补画或数据导出。

## 验证

自动检查覆盖已知比例尺、面积平方换算、比例尺加倍、显示前精度保留、排除状态、无标定、空值/零/负数/非有限值/超长像素输入、图像尺寸不匹配及界面清空函数。5项检查通过。

网页检查以第二张论文示例和演示数字验证交互；这些数字仅供软件测试，不能当作该图片的真实微米测量。

已在网页中确认：输入100/200后显示0.5 µm/px，像素表第1行面积15737.68对应微米表3934.42；勾选编号6后两张表同时标记“已排除”；修改真实长度后微米表消失，输入0会提示错误；重新应用有效输入后换图，两输入框及旧结果全部清空。

自动检查可在项目根目录运行：`python -m unittest discover -s tests -p test_calibration.py`。
