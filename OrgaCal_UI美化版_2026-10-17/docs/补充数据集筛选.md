# 补充数据集筛选

核查日期：2026-10-17。参考用户提供的《类器官项目数据集清单(1).md》，并核对相关原始发布页、论文及已下载的图4数据。

结论：清单有用，最值得新增的是SLiMIA的原图与人工分割配对数据。主线继续采用指定EMBO论文做脑类器官形态复核，外部数据用于检验分割适用性，不替代原论文分组，不据此增加逆设计或硬件诊断模块。

## 清单中需要纠正的内容

1. **R_结果图不是另一份原图或已确认的像素级掩膜。** 本地图3中是带轮廓和编号的可视化结果，不能把原图与R_图重复计数或混合训练。
2. **All_def_results_expanded_with_microns_areaadjusted.csv并非整个类器官的外轮廓参数表。** 已直接读取本地“数据来源图4.zip”的Figure 4/D目录，字段为image、#rosette、#positive、avg distance、avg area、distances、areas、微米换算值、ROI。它对应内部花环状结构分析，不能替代EV1的外轮廓参考数据。
3. **dfRC/dfOS_perbatch_normalized_percentages.csv记录细胞标志物比例。** 已读取字段：Ki67、PAX6、NeuroD2及其组合计数/比例。这不是形态参数相对MAD或圆度分布表。
4. **PA/RC/OS条件标签不等于精确转速或剪切应力标签。** 文件夹批次/细胞系/时点编码可以帮助分组，但不能补出未报告的rpm、轨道直径、液量、局部剪切场和生物结局配对。
5. **CFD生成的转速—流体结果不能充当形态结局真值。** 本项目保持物理估算与图像测量两条可验证的流程，不据这份清单宣称已经能从照片反推最佳转速。
6. **“没有任何公开配对数据”“全部无条件开放”都过于绝对。** 当前只能说：本次核验资料尚未提供足以支持通用转速—剪切—形态预测的完整配对集。使用和发布数据时以具体下载条目的许可为准，不能用论文许可替代数据许可。
7. **三维培养物的照片不自动等于三维体积扫描。** SLiMIA适合当前二维外轮廓流程，但不能据此宣称实现三维体积重建。

## 下一步怎么使用

- 主验证：继续用EMBO图3/EV1，先人工复核少量已关联样本，再检查多目标分割和指标。
- 外部验证：后续从SLiMIA选取一小批原图与人工掩膜，例如30–50对，覆盖不同形状和成像条件；初期不需要下载全部7990张。
- 如果用其中一部分调参或训练，保留独立验证部分，按生物重复/图像序列/批次分组，避免同一个球体的不同时间点跨训练与验证。
- 记录数据集、细胞系、显微镜和比例尺，分别报告脑类器官数据与外部球体数据的表现。外部数据通过不等于脑类器官准确性已证实。
- 有了人工掩膜，既可以验证传统图像算法，也可以在确有必要时训练/微调分割模型；不必为了使用数据而立即更换全部技术路线。
