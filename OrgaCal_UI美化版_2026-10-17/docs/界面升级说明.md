# OrgaCal 界面升级记录

更新日期：2026-10-17（北京时间）。

依据最新申报书与附图册图3的界面组织，使用 ui-ux-pro-max 和 frontend-design 技能调整现有 Gradio 网页。原始申报材料只读，未修改。

## 已落地

- 海军蓝顶栏、青绿主色、白底工作台；桌面左侧五功能导航，综合报告独立入口。
- 剪切参数与计算结果左右分区。显示真实计算范围、平均液深、轨道速度和梯度尺度；空状态提示下一步操作。
- 条件筛选独立成页，沿用剪切预算的设备条件；保留缺参、假设算例、无交集及未校准说明。
- 单图分析按“图片与轮廓—逐目标核对—比例尺标定”组织，原有人工排除及标定清除行为保留。
- 批量形态显示实际图片、候选、排除与失败数量；作者 EV1 数据单独标注。
- 参数、中间量、定义、模型边界与文献依据可展开查看。
- 换算结果由原始 JSON 文本改为可读条件记录；报告仍保留结构化参数。
- 图表采用与工作台协调的色彩，约束图上下排列，便于窄结果栏阅读。
- 手机导航为两行，输入结果单列，单图原图与轮廓上下排列。长表在组件内部横向滚动。
- 浅色、深色分别设置颜色变量；保留键盘焦点，交互按钮至少44px；提供 reduced-motion 样式。
- 改参数时取消相关旧任务并清空结果，减少旧输入结果重新写回的风险。

## 实测核对

- 原有24项单元检查全部通过。
- 剪切、双边界区间、换算、作者数据统计、文献缓存、4图批量、人工排除及报告接口联调通过。
- 浏览器实际操作：剪切计算、换算导航、4张论文原图的75个候选及1张未检出记录、假设条件区间、PDF/CSV/ZIP/Markdown报告生成。
- 375px手机、768px横向/平板、1440px桌面布局检查；形态表格保持内部滚动，图片预览保持原比例。
- 深色主题实际预览，随后恢复浅色。
- 普通系统字体回退，无额外字体下载。
- 物理、约束、形态算法、标定、批处理、统计、报告及文献八个核心模块与升级前逐文件SHA256相同。

## 保留的能力边界

本次主要改进界面与交互。当前物理模型仍为轨道摇床液深梯度尺度假设，未经装置实验校准。没有把附图中的14mPa、12.6mPa、ICC、PC1或候选评分直接当作运行结果。

最新方案中的静置/旋转腔与机械扰动分项预算、CV/ICC、直接PDF或DOI导入、目标形态代理模型与约束优化尚需后续开发和验证。现有相对MAD/PCA、文献检索式与缓存、物理约束敏感性分析继续保留。

图像在运行应用的服务器处理；本地运行时服务器是本机，公开部署时则是部署服务器。文献在线检索会连接Europe PMC。

## 维护位置

- app.py：页面组织与原事件绑定。
- single_ui.py：单图核对与标定布局。
- visual_design.py：品牌、主题与只读结果展示。
- assets/workbench.css：视觉与响应式样式。
- design-system/MASTER.md：设计决策与色彩字体规则。

Gradio6.30会为css参数自动添加选择器前缀，影响根容器和媒体查询。本版将应用自有样式放入launch的head内，避免重复前缀；没有运行时依赖外部CSS框架。

本地入口仍为 http://127.0.0.1:7860。GitHub与魔搭发布状态不因界面升级而改变。
