# OrgaCal · 摇床境算师：开发路线与验收

更新：2026-10-17。依据用户本轮重申的目标、项目策划书及此前复盘。此文件记录开发安排，不表示待开发功能已完成。

## 产品目标与使用顺序

给类器官摇床培养做一台“参数计算 + 形态一致性”工作台。

对外主线：**算剪切 · 找安全区 · 量形状**。

完整操作流程：选择摇床与培养条件 → 输入转速 → 查看剪切应力量级与计算假设 → 查看剪切上界和悬浮/传质下界共同限定的转速区间 → 实验后上传一批照片 → 获取形态一致性报告。文献条件可通过转速换算模块迁移，并能查询原文依据。

页面安排：顶部保留项目名称、定位和主线；优先展示培养前参数计算及可行区间；随后为培养后的形态一致性。转速换算与查文献作为辅助入口；最后汇总报告导出。页面上的功能入口必须如实区分可用与待完成。

## 接下来按此顺序执行

### 1. 算剪切：基础尺度模型已接入

- 先核对适合轨道摇床的模型、公式量纲、几何与校准来源，并写入 `docs/模型假设.md`。
- 输入轨道直径（明确不是轨道半径）、转速、容器/孔型、液量或液深、动力黏度与对应温度。若温度只作记录，不能让界面误示它已经改变计算。
- 输出剪切应力量级/范围（mPa）、所有使用的参数、完整假设、适用条件和出处；说明量级对应何处及何种统计量。
- 验收：单位换算、边界与无效输入检查；可追溯的参考算例；输入改变确实反映在结果中。
- 文献核查时区分CFD模拟与实测、平均值与峰值、不同装置与空间位置。现有形态图像不能直接提供剪切应力训练标签。

### 2. 找安全区：双边界可行区间

- 上界来自选定模型和有明确适用条件的剪切约束。
- 下界同时核查悬浮需求与传质/氧供给需求；必须说明转速如何进入相应模型，不能仅凭组织扩散长度公式生成最低转速。
- 对三个约束取交集，并在图上分别标出每项约束及最终区间。
- 允许输出“无可行交集”或“依据/参数不足，暂不能确定”，同时指出缺失项；缺失下界时不能把单独的剪切上界当作完整安全区。
- 扫描密度差Δρ与耗氧率Q，显示区间随参数变化的情况；区分外部供氧与组织内部扩散限制。
- 验收：上下界都有来源与假设；能覆盖交集为空、边界相等、参数缺失等情况；区间与输入有关，不能把策划书示例“25 mm、6–15 rpm”写成固定默认建议。

### 3. 转速换算

- 输入文献平台与自己的平台条件，包括转速、轨道直径、容器几何和液量等所选准则需要的参数。
- 界面明示换算保持的物理量、采用的模型和适用条件。
- 按已核查的剪切模型求解“等模型剪切”转速；等轨道线速度采用独立模式。
- 延续此前复盘：平方根关系保持n²D，对应轨道加速度尺度，不能未经模型证明直接标成“等剪切”。若保留该关系，单独明确命名。
- 验收：同条件换算返回原转速；正反换算一致；不同准则输出及说明可分辨；缺少必要几何信息时明确缺失项。

### 4. 完成“量形状”的批次一致性部分

- 保留已完成的单图分析和比例尺标定，增加多图输入与批次/条件/时间点/显微镜/倍率信息。
- 补齐策划书所需形态指标，沿用 `docs/指标定义与验收清单.md` 的定义；Circularity与论文Roundness保持不同名称。
- 对照原图、作者结果图和已整理的参数表进行逐目标核对，报告失败样本及误差，明确未能匹配的记录。
- 计算按组和批次定义的相对MAD与PCA；记录特征、标准化、缺失处理和95%椭圆的统计含义。样本不足时给出明确提示。
- 输出目标表、批次汇总、散点图和一致性说明。形态一致性结果不能直接作为某转速具有因果优势的证明。

### 5. 查文献

- 接入文献检索与字段提取：设备、转速、轨道直径、容器/培养体系、类器官类型、时间点及结果。
- 每个提取字段可回到对应论文及原文片段；未报告的字段明确显示“未报告”。
- 按策划书整理至少20条可追溯并完成核对的记录，不从相近论文借填缺失值。

### 6. 综合报告、GitHub与魔搭提交

- CSV导出合并进这一阶段统一完善，不再作为下一步优先于核心计算模块的独立任务。
- 报告包含输入条件、计算假设、剪切估算、各转速边界依据、换算准则、图像核对与比例尺信息、形态一致性统计、引用与局限。
- 提供可复现的安装/运行说明及必要示例；整理代码与材料后发布GitHub仓库，部署魔搭创空间并检查外部访问。
- 最终交付真实可访问的GitHub仓库链接和魔搭部署链接，不以本地网页或空白入口代替。
